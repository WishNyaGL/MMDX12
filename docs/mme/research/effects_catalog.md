# MikuMikuEffect (MME) 100 Most Popular Free Effects Catalog

This catalog compiles the **100 most popular free MikuMikuEffect (MME) effects** for MMD (MikuMikuDance), serving as an empirical test suite reference for native Direct3D 12 reproduction.

## 1. Methodology & Popularity Scoring

Popularity scores (0–100) are evaluated based on real community usage signals recorded during research:
- **NicoNico Commons Content Tree Usage (`子作品数 / 親作品登録数`)**: The official Japanese metric counting how many uploaded videos and illustrations registered the effect as an asset parent (`親作品`). This provides the strongest empirical usage signal in the MMD community (e.g., MME core `sm12149815` with 113k+ uses, AutoLuminous / Soboro pack `sm15369179` with 50.6k+ uses, ExcellentShadow `sm19123817` with 50.3k+ uses, AirDust `sm20916681` with 33.1k+ uses, HgDOF `im2489180` with 28.5k+ uses).
- **BowlRoll Download Counts**: Download metrics from BowlRoll (e.g., `NCHLShader2` with 129,000+ DLs, Soboro re-distribution set with 19,700+ DLs).
- **Curated Community Registries**: Official VPVP Wiki MME directory (`w.atwiki.jp/vpvpwiki/pages/272.html`), LearnMMD.com staple effect tutorials, and NicoNico MMD effect summaries.
- **Developer Repositories**: Public GitHub stars and community adoption (e.g., `Ray-MMD` with 3,100+ GitHub stars).

### Access Requirements
- `open`: Direct public download without credentials or keys.
- `password`: Requires a download key / passphrase (typically documented in the author's video description or readme).
- `login`: Requires a free registered platform account (e.g., BowlRoll account).
- `captcha`: Host enforces anti-bot challenges (e.g., getuploader Cloudflare challenge).
- `dead`: The original distribution host is expired/unreachable; preserved community mirrors are noted.

## 4. Excluded Paid Effects

Per project specification, commercial and paid effects are excluded from the test catalog:
- **ManaShader (まなシェーダー)**: Commercial stylized anime shader pack sold on BOOTH.
- **PostClothShader / PostHairShader Pro**: Commercial character PBR shader suites sold on BOOTH.
- **SunaoShader PBR / Toon Collections**: Commercial cel and PBR material shaders sold on BOOTH.
- **PowerShader v3 / v4 Commercial Editions**: Commercial presets and material packs sold on BOOTH.
- **AnimeToon EX / RealToon MMD Ports**: Commercial Patreon and BOOTH exclusive cel shader sets.
- **MikuEffectStudio 4 (MES4) Premium**: Commercial rendering modules hosted on Patreon / Gumroad.
- **Ray-MMD Reforge Patreon Presets**: Paid material libraries hosted on Patreon/Gumroad.
- **UTS2 / A-Toon MMD Commercial Conversions**: Paid unity-to-MMD shader conversion assets on BOOTH.
- **FluidFX / HyperWater Studio**: Commercial procedural fluid shaders on BOOTH / Gumroad.
- **GenshinShader Fanbox Pack**: Paid fanbox-exclusive anime cel-shading packs.
